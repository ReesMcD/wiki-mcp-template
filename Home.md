**Landing page for the wiki.**

## Start here
- [[Dashboard]]: what's going on right now
- `Log/`: today's quick notes (one file per day)
- `Inbox/`: unsorted notes waiting to be filed

## Folders
- `People/`: people you know, work with or read about
- `Projects/`: things with a goal and an end
- `Topics/`: areas, concepts and recurring subjects
- `Sources/`: books, articles, videos, podcasts and links
- `Notes/`: everything else
- `Private/`: never shared (drafts live in `Private/Drafts/`)

## Conventions
- Frontmatter first, then a **bold one-line summary**, then `## Sections`.
- Link with `[[Page Title]]`; put nicknames in `aliases`.
- Private material: `Private/`, `visibility: private`, `## Private Notes`, `%%comments%%`, or lines containing `(private)`.
- Never delete: set `status: archived` and say why. To rename or re-file a page, ask Claude to move it (every link gets fixed).
